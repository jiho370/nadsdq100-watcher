# 금 배분 타이밍 레짐 신호 시스템 (DXY·실질금리 기반) — 설계

날짜: 2026-08-25
상태: 승인됨 (지호 님, 2026-08-25 — 최초 설계를 "6전략 비교 백테스트"에서
"단일 레짐 신호 시스템"으로 방향 전환한 재설계 버전)

## 배경 / 가설

DXY(달러인덱스)-금은 강한 음의 상관관계가 있지만 고정적이지 않고 시변적이며, 특히
2022년 이후 중앙은행 금매입 급증·지정학 리스크로 전통적인 달러/실질금리-금 관계가
약화되었다는 것이 최근 연구의 공통된 발견이다. 이 프로젝트는 이 전제를 반영해, "지금 금
비중을 늘릴지/관망할지/줄일지"를 판단하는 자산배분 타이밍용 레짐 신호를 설계·검증한다.
단기 매매(잦은 진입/청산)가 목적이 아니라 주간/월간 단위의 비중 조절 판단이 목적이다.

## 목표

DXY·실질금리·국채(IEF) 모멘텀과 금-DXY/금-실질금리 상관관계의 생사 여부를 결합해
"확대(ADD)/관망(HOLD)/축소(REDUCE)" 3단계 + 권고 비중조절폭을 산출하는 레짐 엔진을
만들고, 국면분리 백테스트와 walk-forward/DSR로 통계적 유의성을 검증한다. 최종적으로
현재 시점의 판정 결과와 근거를 출력한다.

## 범위

- **포함**: 데이터/피처 파이프라인(주간 스무딩), 레짐 분류 로직(상관관계 생사 게이팅
  포함), 주간/월간 리밸런싱 백테스트, 4구간 국면분리 검증, walk-forward + DSR(+PBO 참고)
  과최적화 게이트, 현재 시점 판정 출력.
- **제외**: 실계좌 연동/자동매매, 기존 daily_ai_report.py 파이프라인 통합, 일간 스위칭
  전략, 옵션/선물 헤지.

## 설계 결정 (assumption — 이견 있으면 정정)

1. **판단 주기**: 일간 스위칭 금지(스펙 명시). 주간을 기본으로 하되 월간도 파라미터로
   스윕해서 둘 다 비교 리포트에 포함.
2. **포지션 모델**: 금 노출비율 0.6~1.4배(1.0=중립 100%)로 표현. 1.0 초과분(레버리지)·
   미만분(현금)의 조달비용/이자수익은 0%로 가정(연구 목적 단순화 — 실전 적용 시 조달
   비용 반영 필요, 리포트에 명시).
3. **"고정비중 리밸런싱" 벤치마크**: 임의의 고정값을 새로 만들지 않고, **레짐엔진이 실제로
   택한 노출의 시간가중평균**을 상시 유지하는 것으로 정의. "같은 평균 위험노출을 유지하되
   타이밍 스킬만 뺐을 때"와 비교해 신호 자체의 부가가치를 분리해서 본다.
4. **파라미터 3개**: 상관 "살아있음" 임계값(0.25/0.35/0.45), 판단주기(주간/월간),
   비중조절폭 스케일(기본 ±10%·20% / 확대 ±15%·30%) — 총 3×2×2=12조합.
5. **DSR/PBO**: DSR을 필수 헤드라인 통계로, PBO는 `overfit_stats.analyze()`가 같은
   호출에서 같이 내주므로 참고 지표로 병기(이번 스펙은 PBO를 하드 게이트로 요구하지 않음).
6. **금 방향 합의 로직**: 3/6/12개월 모멘텀 부호의 다수결(합이 ≥2 → UP, ≤-2 → DOWN,
   그 외 MIXED=0점). DXY·실질금리·IEF도 동일한 다수결 방식으로 방향 판정.

## 레짐 분류 로직 (핵심)

점수제, 정상 상태(상관관계 중 하나 이상 살아있음) 기준:

| 요소 | 조건 | 점수 |
|---|---|---|
| 금 방향(최우선) | UP 다수결 / DOWN 다수결 / MIXED | +2 / -2 / 0 |
| DXY 컨펌 | corr(금,DXY,60d) 살아있고 DXY DOWN 다수결(→금 강세 컨펌) | +1 |
| | corr 살아있고 DXY UP 다수결(→금 약세 컨펌) | -1 |
| | corr 죽음(임계값 미달) | 0 (죽음 플래그) |
| 실질금리 컨펌 | corr(금,실질금리,60d) 살아있고 실질금리 DOWN(→금 강세 컨펌) | +1 |
| | corr 살아있고 실질금리 UP(→금 약세 컨펌) | -1 |
| | corr 죽음 | 0 (죽음 플래그) |
| IEF 동조 보너스 | 금·IEF 둘 다 UP(완화 레짐) | +1 |
| | 금·IEF 둘 다 DOWN(긴축 레짐) | -1 |

**"설명 안 되는 구간"**: DXY·실질금리 상관이 둘 다 죽어있으면 컨펌·IEF 보너스를 전부
버리고 금 방향 점수만 사용(다른 요소는 계산은 하되 반영하지 않음) + 등급 한 단계 다운캡
(강한 등급이 나와도 약한 등급으로 캡) + `confidence: low` 플래그.

**총점 → 권고**(정상 상태, 총점 범위 -5~+5):

| 총점 | 판정 | 권고 노출 |
|---|---|---|
| ≥3 | ADD(강) | 120% |
| 1~2 | ADD(약) | 110% |
| 0 | HOLD | 100% |
| -1~-2 | REDUCE(약) | 90% |
| ≤-3 | REDUCE(강) | 80% |

설명 안 되는 구간에서는 위 표에서 강한 등급(120%/80%)이 나오면 약한 등급(110%/90%)으로
다운캡.

## 모듈 설계

### 1. `gold_regime_data.py` (1단계)

- `fetch_all()`: Gold(GC=F)/DXY(DX-Y.NYB)/IEF(yfinance) + DFII10/T10YIE(FRED)를 Gold
  거래일 캘린더에 정렬(ffill).
- `build_weekly_features(df)`:
  - 전 시리즈를 주간 리샘플(`W-FRI`, 그 주 마지막 거래일 종가)
  - 금/DXY/실질금리/IEF 각각 13/26/52주 모멘텀 방향(부호)
  - 금-DXY, 금-실질금리 60거래일(≈12주) 롤링 상관계수(일간 데이터 기준 계산 후 주간
    체크포인트에 매핑 — 상관 윈도우 자체가 이미 충분히 길어 스무딩됨)
- 캐시: `output/gold_regime_dataset.pkl`

### 2. `gold_regime_signal.py` (2·3단계)

- `classify(features_row, corr_threshold) -> dict`: 위 표의 점수제 그대로 구현, 근거
  필드(금방향/DXY살아있음·방향/실질금리살아있음·방향/IEF동조/설명안됨여부) 포함해서 반환.
- `build_exposure_series(df, corr_threshold, rebal_freq, weight_scale)`: 매 리밸런싱
  시점(주간 또는 월간)마다 `classify()` 호출 → 목표 노출로 전환, 다음 리밸런싱 시점까지
  유지(그 사이 일간 가격변동은 그대로 반영, 스위칭 없음).
- `simulate_exposure(gold_returns, exposure, cost_bps)`: 턴오버 기반 비용
  (`|Δexposure| × cost_bps`), 리밸런싱 시점에만 비용 발생.
- 벤치마크: 금 buy-hold(exposure≡1.0), 고정비중(exposure≡레짐엔진 평균노출의 시간가중평균).
- 국면분리(`era_performance()` 유사 함수, 이 파일 내 별도 함수로 구현)는
  `regime_era_split.py` 패턴 재사용: 2000년대 강세장(2001-01~2011-08)/2013-15
  약세장(2013-01~2015-12)/2022 금리인상기(2022-03~2023-07)/2022년 이후(2022-01~현재)
  4구간. 2022년 이후 구간에서 "설명 안 되는 구간" 태깅 빈도와, 그때 보수적 판정이 실제로
  낙폭을 줄였는지 별도 확인.

### 3. `gold_regime_overfit_gate.py` (4단계)

- 파라미터 그리드(corr_threshold × rebal_freq × weight_scale, 12조합)의 월간 비중첩
  초과수익(vs 고정비중 벤치마크) 행렬을 `overfit_stats.analyze()`에 투입 → DSR(헤드라인)
  + PBO(참고) 동시 산출. 시도한 조합 수(12) 결과 JSON에 기록.
- Walk-forward: expanding window, 최소 학습 5년 → 1년씩 테스트, 매 스텝 학습구간 내
  Ulcer 개선 기준 최고 조합 선택 → 다음 1년 OOS 적용, 체이닝.
- 비용 민감도: 5bp/15bp 두 코스트로 재실행, 델타 보고.

### 4. `gold_regime_report.py` (5단계)

- 백테스트 리포트: 국면별 성과표(CAGR/Ulcer/MDD/buy-hold·고정비중 대비 우위), DSR/PBO,
  "설명 안 되는 구간" 발생 빈도·2022년 이후 보수적 판정의 효과, 다중검정 조합 수.
- **현재 시점 판정**: 최신 데이터로 `classify()` 1회 호출 → ADD/HOLD/REDUCE + 권고
  노출 + 근거(금 방향/DXY 상관 생사·방향/실질금리 상관 생사·방향/IEF 동조/신뢰도) 출력.
- 산출물: `output/gold_regime_report.md`(서술형) + `output/gold_regime_summary.json`
  (표 데이터 + 현재 판정).

## 검증 계획

- 각 모듈에 `--self-test`(합성 데이터로 배선 확인, 저장소 기존 컨벤션과 동일)
- 실행 순서: data → signal(백테스트+국면분리) → overfit_gate → report
